## description

```
站在你自己的房间里，伸手握住那根扶杆。握住的那一刻，一架运输机从你手边长出来：货舱、红色夜灯、放下的尾舱门，门外是一万八千英尺的高空。等跳伞灯变绿，松手，你就掉下去了。

Freefall 是 Apple Vision Pro 上的第一人称高空跳伞，用你自己的手来玩。

自由落体
加速到终端速度，穿过一层正在下雨的云：雾从脚下往上急掠，雨点从身边嗖嗖地掠过，手套和袖子越来越湿。穿出云底还在雨里，再往下才是晴天。

开伞
高度表戴在你的手腕上。3,500 英尺它会报警：用另一只手抓住小臂上的红色拉环，往外拉。引导伞把伞包拽出去，伞绳拉直，伞衣在你头顶一格格鼓起来。拉得太晚，就没有足够的高度了。

伞下飞行
伞下转头、转身来转向，伞跟着你转；抓住操纵环两边一起拉是减速，往前推是俯冲。点一下手表，头盔里的 HUD 显示高度、航向和降落点。落进地上红白相间的圆圈就赢，落进正中的黄色靶心是完美着陆。

七关
• 环礁——碧蓝潟湖里的一片白沙洲，落短了就掉进水里。
• 草原——拼布一样的农田，一条弯弯的河和树林挡在你和降落点之间。
• 高山——U 形山谷，开伞时两边的山比你还高。
• 雪山——空气稀薄，掉得更快，得早点开伞。
• 海岛——在海上开伞，越过珊瑚礁飞上岛，别落进雨林。
• 火山——正在喷发的火山锥、熔岩流和一柱火山灰，都得躲开。
• 天空之城——云海上的浮空岛，岛上一座废弃的石头城。

每一跳的风都不一样，没有两次进场是相同的。

赢来的装备
每关都有一顶自己的降落伞和一套手套、袖子，图案都来自那一关的景物。落进这一关的降落点解锁它的伞，落进靶心再解锁它的手套和袖子。

练习和回看
一关平安落地过一次以后，可以直接从 5,000 英尺开始，专门练开伞后的飞行。每跳完一次，航线图从上往下给你看整段飞行，落长还是落短、偏左还是偏右。

为舒适而设计
• 建议坐着、戴耳机玩。
• 默认靠转头、转身转向，世界不会绕着你转。也可以打开「拉环转向」，打开前会提醒可能引起晕动症。
• 快落地时自动拉平；也可以改成手动，自己拉平。
• 一跳大约四分钟。任何时候按住手表两秒就能退出。

实时生成
除了手套，你看到和听到的一切都是边玩边生成的：飞机、降落伞、云、海和山。不需要账号，没有广告，不收集任何数据，不联网也能玩。支持十种语言。

需要手部追踪。

音效「wind 2」「parachute 2」「nylon flapping 1」来自 freesound.org 的 Huggy13ear，按 CC BY 4.0 许可使用。
```
