## description

```
自分の部屋に立ったまま、目の前のバーに手を伸ばしてください。握った瞬間、その手元から輸送機が生まれていきます。貨物室、赤い夜間灯、開いた後部ランプ、そしてその先には高度18,000フィートの空。ジャンプランプが緑に変わったら手を離して、落下開始です。

Freefall は、Apple Vision Pro で自分の手を使って遊ぶ、一人称視点のスカイダイビングです。

フリーフォール
終端速度まで加速して、雨を降らせる雲の層へ。霧が足元から一気に駆け上がり、雨粒が横をすり抜け、グローブと袖がだんだん濡れていきます。雲底を抜けてもまだ雨。その下でようやく晴れ間に出ます。

開傘
高度計は手首に。3,500フィートでアラームが鳴ったら、もう片方の手で前腕の赤いハンドルをつかんで引きます。パイロットシュートがキャノピーを引き出し、ラインが張り、セルがひとつずつ膨らんでいきます。引くのが遅すぎると、空が足りなくなります。

キャノピー操縦
頭と体の向きを変えれば旋回し、キャノピーがついてきます。トグルを両方引けば減速、前に押せば急降下。時計をタップすればヘルメットの HUD に高度、方位、着地点が表示されます。地上の紅白の円に降りれば成功、中央の黄色いブルズアイなら完璧な着地です。

7つのステージ
• 環礁 ― 青いラグーンに浮かぶ白い砂州。手前に落ちれば水の中。
• 草原 ― パッチワークの畑。曲がりくねる川と林が着地点の手前に。
• 高山 ― U字谷。開傘した時、両側の山はあなたより高い。
• 雪山 ― 空気が薄く落下が速いので、早めの開傘を。
• 南の島 ― 海の上で開傘し、サンゴ礁を越えて島へ。熱帯雨林には降りないこと。
• 火山 ― 噴火中の火山、溶岩流、噴煙の柱を避けて。
• 天空の都 ― 雲海に浮かぶ島々と、そこに残る石造りの廃都。

ジャンプごとに風が変わるので、同じアプローチは二度とありません。

装備を勝ち取る
ステージごとに、その景色をモチーフにしたキャノピーとグローブ・袖があります。着地点に降りるとキャノピーが、ブルズアイに降りるとグローブと袖がアンロックされます。

練習とふり返り
一度無事に着地したステージは、5,000フィートからキャノピー操縦だけを練習できます。毎回のジャンプ後には、飛行経路を真上から表示。長すぎたか短すぎたか、左右どちらにずれたかがわかります。

快適さを考えた設計
• 座って、ヘッドホンを付けてのプレイがおすすめです。
• 初期設定では頭と体の向きで旋回するので、周りの世界が回転することはありません。トグルでの旋回もオプションで選べます（オンにする前に乗り物酔いの注意が表示されます）。
• 着地直前のフレアは自動。手動に切り替えて自分でフレアすることもできます。
• 1回のジャンプは約4分。時計を2秒長押しすればいつでも終了できます。

リアルタイム生成
グローブ以外、見えるもの聞こえるものはすべてプレイ中に生成されます。輸送機、キャノピー、雲、海、山。アカウント不要、広告なし、データ収集なし、オフラインでも遊べます。10言語に対応。

ハンドトラッキングが必要です。
```
