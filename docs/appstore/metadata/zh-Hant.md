## description

```
站在你自己的房間裡，伸手握住那根扶桿。握住的那一刻，一架運輸機從你手邊長出來：貨艙、紅色夜燈、放下的尾艙門，門外是一萬八千英尺的高空。等跳傘燈變綠，放手，你就掉下去了。

Freefall 是 Apple Vision Pro 上的第一人稱高空跳傘，用你自己的雙手來玩。

自由落體
加速到終端速度，穿過一層正在下雨的雲：霧從腳下往上急掠，雨點從身邊咻咻掠過，手套和袖子越來越濕。穿出雲底還在雨裡，再往下才是晴天。

開傘
高度計戴在你的手腕上。3,500 英尺時它會警報：用另一隻手抓住小臂上的紅色拉環，往外拉。引導傘把傘包拽出去，傘繩拉直，傘衣在你頭頂一格格鼓起來。拉得太晚，就沒有足夠的高度了。

傘下飛行
傘下轉頭、轉身來轉向，傘跟著你轉；抓住操縱環兩邊一起拉是減速，往前推是俯衝。點一下手錶，頭盔裡的 HUD 顯示高度、航向和降落點。落進地上紅白相間的圓圈就贏，落進正中的黃色靶心是完美著陸。

七個關卡
• 環礁——碧藍潟湖裡的一片白沙洲，落短了就掉進水裡。
• 草原——拼布般的農田，一條彎彎的河和樹林擋在你和降落點之間。
• 高山——U 形山谷，開傘時兩邊的山比你還高。
• 雪山——空氣稀薄，掉得更快，得早點開傘。
• 海島——在海上開傘，越過珊瑚礁飛上島，別落進雨林。
• 火山——正在噴發的火山錐、熔岩流和一柱火山灰，都得避開。
• 天空之城——雲海上的浮空島，島上一座廢棄的石頭城。

每一跳的風都不一樣，沒有兩次進場是相同的。

贏來的裝備
每個關卡都有一頂自己的降落傘和一套手套、袖子，圖案都來自那一關的景物。落進這一關的降落點解鎖它的傘，落進靶心再解鎖它的手套和袖子。

練習和回顧
一個關卡平安落地過一次以後，可以直接從 5,000 英尺開始，專門練開傘後的飛行。每跳完一次，航線圖從上往下呈現整段飛行，落長還是落短、偏左還是偏右。

為舒適而設計
• 建議坐著、戴耳機玩。
• 預設靠轉頭、轉身轉向，世界不會繞著你轉。也可以開啟「拉環轉向」，開啟前會提醒可能引起動暈症。
• 快落地時自動拉平；也可以改成手動，自己拉平。
• 一跳大約四分鐘。任何時候按住手錶兩秒就能退出。

即時生成
除了手套，你看到和聽到的一切都是邊玩邊生成的：飛機、降落傘、雲、海和山。不需要帳號，沒有廣告，不收集任何資料，不連網也能玩。支援十種語言。

需要手部追蹤。
```
